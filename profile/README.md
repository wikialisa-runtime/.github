## 👋 Welcome to the Open Source Social Network (OSSN)!

**Open Source Social Network (OSSN)** is a powerful, lightweight, and open-source social networking software that lets you create your own social platform with ease.

### 🌟 What is OSSN?

OSSN is designed to be simple, extensible, and scalable. Whether you're building a private community, a niche network, or a public social platform. OSSN gives you the tools to get started quickly.

- 🛠️ **Built with PHP**
- 🧩 **Modular architecture** – Extend functionality with components and themes
- ⚡ **Lightweight and fast** – Minimal server resources required
- 📱 **Responsive design** – Works on desktops, tablets, and phones
